# Funcionalidades implementadas por IA

A versão inicial do Revi foi construída com base no nosso projeto puro em HTML, CSS e Javascript. A princípio optamos por utilizar o Tanstack Router, pois havíamos testado na beta há muito tempo atrás, além de Tailwind, React e Typescript. A partir dessa versão inicial (Disponível na branch `v1`), iniciamos um processo de melhoria manual e com a ajuda de IA para implementação de novas features.

Abaixo estão as funcionalidades que contamos com a ajuda de IA para implementação:
- [x] Geração dos dados mockados e seed do banco de dados.
- [x] Ajuda na migração do Tanstack Router para o React Router.
- [x] Implementação do modo de estudo através de mapa mental utilizando a biblioteca React Flow.
- [x] Integração com a API do Spotify para tocar músicas durante o estudo.
- [x] Integração com as rotas do back end através da nossa documentação de API.
- [x] Implementação do fluxo de autenticação e autorização com JWT.
